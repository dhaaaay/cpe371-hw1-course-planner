# Student Course Planner

## Product Vision

Student Course Planner is a Java console application that helps students manage course planning by adding courses, viewing available courses, searching for courses, and registering students in courses.

## Main Features

- Add a course
- List all courses
- Search for a course by course code
- Register a student in a course
- Display all full courses
- Exit the application

## How to Compile and Run

Open a terminal in the project folder.

Compile the program:

```bash
javac src/*.java
